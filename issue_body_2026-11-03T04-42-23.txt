
# ICON External Parameter Request

## Request: Patagonia and Drake Passage — nested ICON grids

This request aims to generate three successively nested regional ICON grids for Patagonia and the Drake Passage, using the existing global MPIM grid `icon_grid_0049_R02B04_G.nc` as the parent.

The requested grid hierarchy is:

- DOM01: R02B04 — global parent grid (~160 km)
- DOM02: R02B05 — broad South American/Southern Ocean region (~80 km)
- DOM03: R02B06 — Patagonia and Drake Passage (~40 km)
- DOM04: R02B07 — higher-resolution regional domain (~20 km)

The request includes external parameter generation (EXTPAR) and topography diagnostics for all four domains.

## Previous execution and proposed correction

The initial configuration (`v1`) failed during ICON grid generation.

The grid-generation log reported:

- DOM02: 445 cells marked for refinement; 1,780 cells generated.
- DOM03: 0 cells marked for refinement.
- The grid generator terminated with `STOP 99`.

The previous regional domain extents may have been insufficient for the required nesting and boundary zones.

This revised configuration (`v2`) enlarges DOM02 and DOM03 and adjusts DOM04 to improve the nesting geometry.

The correction has not yet been validated by a successful grid-generation run.

## Intended application

The resulting grids are intended for an ICON-NWP atmospheric simulation over Patagonia and the Drake Passage, including atmospheric dynamics, regional climate variability, and subsequent analysis of model-generated time series.

The computational environment uses ICON 2025.10 on an HPC cluster.

Once the grid and EXTPAR files are available, their compatibility with the atmospheric configuration and land-surface setup will be checked independently.

Thank you for processing this revised request.
